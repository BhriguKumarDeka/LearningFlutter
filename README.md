## How to Run

### Command Line Tools (Dart)
To run the CLI apps, navigate to the respective directory and use the dart CLI:
```bash
cd dartpedia/cli
dart run bin/cli.dart
```

### Flutter Apps
To run the Flutter applications:
```bash
cd practice/learning_flutter
flutter pub get
flutter run
```
